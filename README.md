# QuickBox

QuickBox 是 Windows 本地个人信息管理工具。网站项目可保存网站地址、用户名、密码、登录方式和备注，也可只保存名称；另有常用命令项目。

左侧切换全部、网站和常用命令；单击项目查看详情，双击有地址的网站项目打开链接。右键列表中的项目可复制网址、用户名、密码或命令，也可调整顺序。编辑和删除位于详情区域，删除需要确认。

默认使用智能排序：打开网站或复制网址、复制命令时计入使用；单击查看、复制用户名或密码不会计入。使用分数按 14 天半衰期衰减，每个项目只保存分数和最后更新时间，不保存操作历史。在列表右上角可切换至手动排序，再右键项目上移或下移。

## 数据与安全

数据保存在 `%LOCALAPPDATA%\QuickBox\data.db`，与安装目录分开，安装和卸载不会删除此目录。首次使用需要设置主密码；**主密码遗失后无法恢复已加密的密码**。密码使用 Scrypt 派生密钥和 AES-256-GCM 加密；名称、链接、用户名、命令和备注以明文存储。复制密码 30 秒后或正常退出程序时，仅当剪贴板仍是该内容时清除。请自行备份整个数据目录，并妥善保管备份和主密码。

数据库通过 SQLite `user_version` 管理结构版本；升级前使用 SQLite 备份 API 保存备份，拒绝打开更高版本。旧版网站、账号和文档会迁入统一的网站类型，原有字段和加密密码保留。备份位于数据目录，文件名为 `data.db.backup-时间戳`。

## 开发运行

需要 64 位 Python 3.10–3.12。建立虚拟环境并安装 `requirements-build.txt`，然后运行：

```powershell
python -m quickbox
python -m pytest tests -q
```

构建安装程序需要 PyInstaller 和 Inno Setup 6。安装依赖后运行 `./build.ps1`；若 ISCC 不在默认路径，传入 `-Iscc "路径\ISCC.exe"`。产物在 `dist`，仅供本地使用。安装程序仅管理安装目录，数据目录不属于安装清单。

## 版本与发布

版本在 `quickbox/version.py` 统一维护；更新历史见 `CHANGELOG.md`。公开仓库为 https://github.com/jinhua666/QuickBox。左下角“检查更新”读取该仓库最新正式 Release，并显示版本与更新说明。确认下载后，软件检查安装包大小及 GitHub API 提供的 SHA-256 摘要，再经用户确认启动安装程序；它不会上传本地数据或主密码。摘要校验不等同于数字签名，当前安装包尚未签名。没有 Release 时不会提供安装包。只有获得用户明确许可后才能推送发布代码、打标签、创建 Release 或上传安装包。
