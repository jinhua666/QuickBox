# QuickBox 架构设计

## 范围

QuickBox 是仅在 Windows 本地运行的个人信息工具。统一的“网站”类型保存网址、账号、密码、登录方式和文档链接，另有“常用命令”类型；支持搜索、排序、增删改、复制与打开。没有云同步。

## 组件

- `quickbox/storage.py`：SQLite 数据库、版本检查和迁移备份、条目持久化、主密码与加密。
- `quickbox/ui.py`：PySide6 解锁、导航、列表、详情和编辑操作；依赖存储层而不直接操作 SQLite。
- `quickbox/updates.py`：读取公开 GitHub Release 的版本、说明和安装包摘要，下载并校验文件；不读取用户数据库，也不需要令牌。
- `quickbox/update_dialog.py`：在后台线程检查、下载，用户确认后启动安装程序。
- `quickbox/__main__.py`：程序启动入口。`quickbox/version.py` 是版本号唯一来源。
- `installer/`：PyInstaller 和 Inno Setup 的本地构建配置；安装和卸载只处理程序文件。

## 存储与安全

数据位于 `%LOCALAPPDATA%/QuickBox/data.db`，不在安装目录。用 SQLite `user_version` 标识数据库结构；迁移现有数据库前以 SQLite 备份 API 创建独立备份，拒绝打开更高版本的数据库。第 2 版将账号、文档统一归入网站并增加登录方式，旧收藏字段保留但不显示；第 3 版为每个项目增加衰减分数和最后更新时间。首次创建时生成随机盐，用 Scrypt 派生 256 位密钥，使用 AES-256-GCM 加密验证标记和每个密码。遗失主密码无法恢复。名称、地址、用户名、登录方式、命令和备注不加密，属于本机明文元数据。密码复制 30 秒后仅在剪贴板仍保留原内容时清空。

## 发布与更新

本地阶段构建不发布。正式发布必须先获得用户明确许可，再确定高于已安装版本的语义化版本、构建、提交推送、打标签和创建 Release。更新模块读取公开仓库正式 Release，匹配 `QuickBox-Setup-{版本号}.exe`，校验 GitHub API 提供的 SHA-256、文件大小和下载地址；用户确认后才启动安装。摘要校验不提供独立的代码签名保证。安装和升级不得触及用户数据。
